# O caso Semmelweis: análise de dados e comunicação para decisões que salvam vidas

## Problema
Em Viena do século XIX, um médico usou análise exploratória de dados para provar algo revolucionário: lavar as mãos salvava vidas. Mesmo com números inquestionáveis, ele foi ignorado, ridicularizado e morreu sem ver sua descoberta reconhecida. Estar certo nos números não foi suficiente — e não é suficiente hoje.

## Abordagem
O caso real de Semmelweis como fio condutor para uma aula prática de análise de dados aplicada à tomada de decisão:
- Por que comparar taxas em vez de valores absolutos
- Como um gráfico bem escolhido revela um padrão que uma tabela escondia
- Como saber se a diferença observada é estatisticamente relevante ou apenas ruído

Na segunda parte, os três erros de comunicação mais comuns de quem trabalha com dados — falar em jargão técnico com quem decide, culpar o interlocutor pela resistência, e ignorar a objeção real por trás da pergunta — e como corrigir cada um deles na prática.

## Dados & Ferramentas
Análise exploratória de dados, comparação de taxas, testes de significância estatística, técnicas de comunicação de dados para não especialistas.

## Resultado
Roteiro para estruturar análises exploratórias orientadas a decisão, critérios práticos para escolher entre tabela e gráfico e validar se uma diferença é real ou aleatória, e técnicas de comunicação para traduzir resultados técnicos em ação para quem não é do time de dados.
