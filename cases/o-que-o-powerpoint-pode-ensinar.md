# O que o PowerPoint pode ensinar sobre seus dashboards de Power BI

## Problema
Um dashboard bonito nem sempre é um dashboard eficiente. Um colega perguntou como melhorar seus painéis em Power BI, e a resposta não veio de um curso de BI, mas de um curso de design de apresentações — as duas coisas têm mais em comum do que parece: ambas envolvem criar algo visual para comunicar uma mensagem a uma audiência específica.

## Abordagem
Cinco princípios de design de apresentação traduzidos diretamente para a construção de dashboards:
- Definir o objetivo antes de abrir a ferramenta
- Pensar na audiência para escolher o nível certo de detalhe
- Montar um layout que reduza o custo cognitivo de quem vai ler o painel
- Usar cores com significado, não decoração
- Manter consistência visual entre páginas para não cansar quem usa o relatório no dia a dia

Encerramento com dicas práticas sobre como escolher o tipo de gráfico certo para cada tipo de dado.

## Dados & Ferramentas
Power BI, princípios de design de apresentação aplicados a dashboards.

## Resultado
Checklist de design para aplicar no próximo dashboard, antes mesmo de abrir o Power BI.
